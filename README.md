# READ ME

Configure and run using the `augment_demo.py` script.

Visual Studio Code is recommended.

## Folder Structure

Place the `augment_demo.py` script alongside the dataset folders.

```text
augment_demo/
    .vscode/

    dataset_tu/ <- the dataset folder
        1.jpg
        2.jpg
        ...

    processed/tu/
        Affine_rotate
        Affine_scale
        ...

    .gitignore

    augment_demo.py <- the script
    
    README.md
```
